# 正文组件

后台编辑栏的「插入组件」可加入以下模板，前台与后台预览使用相同语法。
普通 Markdown 仍然照常使用，无需重新保存已有文章。

## 提示框

`note`、`info`、`tip`、`warning`、`danger` 分别提供不同语气的提示。

```markdown
:::tip{title="小建议"}
先写下一个小想法，再慢慢补充 **细节**。
:::
```

## 折叠内容

```markdown
:::details{title="展开查看推导"}
这里放详细说明，也可以加入代码和公式。
:::
```

添加 `open="true"` 可默认展开。折叠内部标题不加入外部文章目录。

## 标签页

外层比内层多用一个冒号，以明确嵌套边界。

```markdown
::::tabs{title="操作系统"}
:::tab{title="Windows"}
Windows 的操作说明。
:::
:::tab{title="macOS"}
macOS 的操作说明。
:::
::::
```

支持方向键、Home 和 End 切换；各标签页内的标题不加入外部目录。

## 步骤

```markdown
::::steps{title="准备发布"}
:::step{title="整理内容"}
补充背景和例子。
:::
:::step{title="检查并发布"}
预览格式，填写摘要和标签。
:::
::::
```

## 图片组

先通过后台上传图片，再把正文中的图片链接放进图片组。不同图片之间保留空行。
图片组中的图片仍可点击放大。

```markdown
:::gallery{title="周末的一些瞬间"}
![图片说明](/media/替换成实际图片文件名.png)

![另一张图片](/media/替换成另一张图片文件名.png)
:::
```

## GitHub 仓库卡片

```markdown
::github{repo="Axi404/Axi-Theme" description="这里可以写项目简介。"}
```

卡片进入可视范围后尝试读取公开的仓库描述、语言和 Star 数；请求失败时仍保留可点击的链接及手写简介。仓库资料通过固定的 GitHub API 地址读取，文章无需提供令牌。

这些组件不会执行 MDX、HTML 或 JavaScript。组件名称和属性按固定名单处理，正文和属性中的文字会作为普通文本显示。
